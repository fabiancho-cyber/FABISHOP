# FABI SHOP - Premium E-commerce Frontend

A modern, high-performance, and fully responsive e-commerce web application built from scratch. Designed with a premium dark aesthetic focused on urban fashion and seamless user experience.

👉 **[Haz clic aquí para ver el proyecto en vivo]https://fabiancho-cyber.github.io/FABISHOP/

## 🛠️ Tech Stack & Architecture

This project was built using professional workflows and the modern frontend stack:

*   **Bundler & Environment:** Vite (For lightning-fast development, hot reloading, and highly optimized production builds).
*   **Language:** TypeScript & JavaScript ES6+ (Implementing strong typing, strict type-checking, and modern asynchronous logic).
*   **Package Manager:** pnpm (Fast, disk space efficient package management).
*   **Styling & Layout:** Semantic HTML5 and Advanced CSS3 (Leveraging CSS Grid, Flexbox, and fluid typography hierarchies for cross-browser consistency).
*   **Data Management:** Local JSON data architecture, separation of concerns between raw product data and DOM rendering layers.

---

## 🌟 Key Features

*   **Dynamic Client-Side Filtering:** High-performance, zero-latency catalog filtering system (All, Shirts, Hoodies, Pants) powered entirely by TypeScript DOM manipulation.
*   **Conversion Rate Optimization (CRO):** Deep-linked "Order via WhatsApp" integration that automatically formats personalized purchase requests based on the selected item's details.
*   **Premium UX/UI Layout:** Fully responsive layout with custom design patterns inspired by top-tier modern fashion brands.
*   **Product Recommendations Carousel:** Smart contextual "You May Also Like" product injection section to boost user retention.

## 🚀 How to Run Locally

If you want to clone this repository and test it on your local machine, follow these steps:

1. Clone the repository:
```bash
git clone https://github.com
```

2. Install dependencies:
```bash
pnpm install
```

3. Start the development server:
```bash
pnpm dev
```
